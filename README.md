# 小兔的月亮灯 · 晚安绘本

五页儿童睡前绘本，每页一幅大图、两句话，结尾为「晚安」。

- 点击「听故事」播放阶跃星辰温柔女声；默认连续朗读，读完自动翻页，到第五页停止。
- 支持手动翻页、页码跳转、方向键、手机滑动和翻页音效开关。
- 可以关闭「连续播放」，仅朗读当前页。
- 所有插画和音频均包含在仓库中，浏览器无需 API Key。

## GitHub Pages

发布源：`main` 分支，根目录 `/`。推送更改后，GitHub Pages 自动更新网站。

## 本地预览

```sh
python3 -m http.server 4173
```

打开 http://localhost:4173。

## 内容与配音

插画由 ImageGen 生成。配音使用阶跃星辰 `stepaudio-2.5-tts`，温柔女声 `wenrounvsheng`，语速 0.85。
仓库只包含成品音频，不包含 API Key 或账号配置。
